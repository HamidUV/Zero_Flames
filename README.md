🔥 Zero Flames – Fire & Safety Website

A modern, responsive website built for Zero Flames, a fire protection and safety solutions company based in Kerala.
The site showcases their services, Fire NOC consultancy, and safety system installations with a clean, professional design and SEO-friendly structure.

✨ Features

🚒 Fire & Safety services showcase

📄 Fire NOC consultancy details

📞 Contact methods & inquiry form

📱 Fully responsive design (mobile-first)

🎨 Classic & modern UI with animations

⚡ Built with React + Tailwind CSS + Vite
